HOUSE OF FLAVORS - SIMPLE ORDER WEBSITE

1. Open index.html in VS Code.
2. Find WHATSAPP_NUMBER and replace 15550000000 with the owner's WhatsApp number including country code, digits only.
3. Find products and replace each price:null with a real number, e.g. price:8.50. Change CURRENCY if needed.
4. Open index.html in a browser to test. Add items, enter delivery information and send a test WhatsApp order.
5. Upload index.html AND the images folder to GitHub Pages or another static website host.

IMPORTANT: This version does not store orders on a server. The customer must press Send in WhatsApp to submit the order. If you need orders saved even when the seller is offline, connect a hosted form/database service in a future version. Delivery charges are confirmed manually. No online payments.
